# MRK Website Factory

Free-first website generation pipeline.

## Input
- niche
- business name
- location (optional)

## Output
- portable JSON site specification
- page map
- SEO metadata
- deployment targets

## Safety
The factory prepares files and deployment plans. Publishing to a live website remains an approval-gated action. It never handles passwords, OTPs, bank details, identity verification, or payment transfers.
